# 🏆 Master Flag League

Sistema Integral de Gestión de Liga de Flag Football - Cancún, Quintana Roo, México

## 📋 Estructura del Proyecto

```
master-flag-league/
├── backend/              # API REST (Node.js + Express)
├── frontend/             # Aplicación React
├── docs/                 # Documentación
├── .gitignore            # Git ignore
└── README.md             # Este archivo
```

## 🚀 Tecnología

### Backend
- Node.js + Express + TypeScript
- PostgreSQL
- JWT Authentication
- Cloudinary (almacenamiento de documentos)

### Frontend
- React + TypeScript
- TailwindCSS + DaisyUI
- React Query + Zustand
- Vite

## 📊 Fases de Desarrollo

- **FASE 1: CORE** (2-3 semanas)
  - Autenticación y roles
  - Gestión de usuarios y equipos
  - Registro y validación de jugadores
  - Sistema de documentos

- **FASE 2: COMPETENCIA** (2-3 semanas)
  - Jornadas y generador automático
  - Partidos y modo árbitro
  - Sincronización en tiempo real

- **FASE 3-6**: Estadísticas, Finanzas, Experiencia, Playoffs

## 🔧 Setup Local

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
